Authority: [issue #53](https://github.com/nicolas-found42/sl-remastered/issues/53) and [full specification](../specs/full-port-1.0.0.md), read on 2026-11-02. This is the current acceptance map; [the older checklist](../parity-checklist.tsv) supplies historical discovery leads only. Requirement IDs below remain stable. A compound row requires every listed clause; split newly discovered variants into suffix IDs without weakening its parent.

Status vocabulary: **missing** (required implementation or acceptance evidence is absent), **implemented but unverified** (the path exists, full acceptance remains unproved), **contradicted** (retained evidence fails a required assertion), **verified** (the entire row has current bound acceptance evidence). No product or D1–D8 row is currently verified. Locations are inspected source or explicit reading leads, not an implementation-completeness claim. `none` means no qualifying bound evidence was found in this bounded audit; it does not assert no historical observation exists.

Reference decision **R** applies to every gameplay row: compare both identity-bound official references; choose newer behavior, retain older-only features, explicitly resolve incompatible combinations, preserve remaining Stock quirks. E-PROVENANCE2 resolves local Build606/940 labels; current metadata and build labels do not authenticate either distribution; [the provenance investigation](reference-distribution-provenance.md) records the missing distribution-to-file chain. **P** denotes a product/release requirement imposed by the specification rather than a Stock behavior. **C** denotes the sole approved authentic-CD exception; synthetic CD disclosure remains, ordinary file audio/video remains required.

Acceptance **J** means declared equivalent stimuli, independent repeats on each side, strict paired evaluator, all applicable success/refusal/cancellation/repetition/interruption/recovery/persistence/cleanup variants, exact values initially, and field-specific tolerance only after Stock repeatability justification. Each gameplay row needs its own content/variant contracts and Journey evidence; this shorthand does not waive them.
