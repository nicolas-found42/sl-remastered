# Conditional original Dyno oracle

`dyno_oracle.py` and `dyno_newer_oracle.py` compile the corresponding
`tests/wine_original_dyno*_test.c` fixture. Compilation is the default; explicit
`--execute` additionally runs the qualified ARM64 private-prefix console route.
Both require fresh prepaid capacity, a unique direct child of an existing
registered parent, shared Stock admission and preservation of all old files.
They do not start the original game, qualify its normal script initialization,
or establish paired whole-game parity.

The original executable is source-hash checked before mapping. Every original
code byte is compared before declared HIGHLOW relocations. Only bounded
allocator entry substitutions are published; no world, discovery, profile,
registration, combustion, table or math patch is installed. Allocation ownership
and leak checks remain mandatory. The conditional allocator zero-initializes
fresh memory, so this does not establish actual game allocation initialization.

The older source is SHA256
`7d77466a8c1a34d16a59d9ccf2e8059664dff1bfb421338074a461a932e8edde`.
The newer source is SHA256
`f44fb88a4335c657e20701cdb84afb8d1d85f7c3aceb93d30113e6e6e44fefc2`.
Build receipts bind the retained REA source packets, exact allocator guards,
constructor/reset/table/destructor ABI and all copied source hashes.

The seven input cases are defaults, same-object default recalculation, turbo,
intercooling, nitrous, valve timing and fuel/air limits. Each requests 16 table
steps, yielding integer step 437 and count 16. Results retain raw IEEE words for
four curves, six primary statistics captured before nitrous calculation, and
all 116 state words. Raw records are never rounded to match the Port model.

The newer fixture also recalculates primary with nitrous disabled on the same
object and checks that existing secondary curves persist. Three separate
copied-state, one-step combustion controls retain raw input/output: negative
minimum/total/prior volume, tiny volume, and a zero-swept-volume cycle transition.
These are conditional native-state boundary controls, not game observations.
They preserve the source object's ownership and never destroy the copied table
pointers.
